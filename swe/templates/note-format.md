# Note / PDF Format (applies to every course, every semester)

Keep this structure the same across all courses — only the accent color
(from [colors.md](../colors.md)) changes per course.

```
# {Course Name} — {Topic}

Course Code: {code}   Date: {YYYY-MM-DD}

## Key Points
- ...

## Details
...

## Summary
...

## References
- ...
```

- Header/accent color in generated PDFs = that course's color from colors.md.
- File naming: `notes/YYYY-MM-DD-topic-slug.md` (and its generated `.pdf`
  alongside it once asked for).
- Don't invent topics/content — only generate notes from material the user
  actually provides (slides, books, class content) or explicitly asks for.
