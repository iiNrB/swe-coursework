# SWE

Root folder for my 4-year B.Sc. in Software Engineering coursework at
Islamic University of Technology (IUT), OIC, Gazipur. Started October 2026
(1st year, 1st semester).

## Per-course folder structure

Every course under `semester-N/<course>/` follows this layout (not every
course has every folder — only what's actually been provided):

```
<course>/
├── README.md, syllabus-routine-notice.md, cover-page.*
├── outline/          — official course outline/catalogue docs
├── slides/
│   ├── (raw lecture slides; batch-named subfolders only if multiple exist)
│   └── handouts/     — generated Part 1/Part 2 print handouts (3 slides/page + notes)
├── books/             — textbook PDFs
├── lab-tasks/         — lab task sheets / lab manual, for courses with a lab
├── notes/             — my own notes, formatted per templates/note-format.md
├── shared-notes/      — other students'/teachers' shared reference notes (not mine)
├── exam-questions/    — this semester's current mid-term/final
└── past-exams/        — older years' mid-term/final papers, for practice
```
