# C Practice

Your own C programs and LeetCode solutions go here, as you write them
yourself, following [c-programming-leetcode-roadmap.md](../c-programming-leetcode-roadmap.md).

Suggested layout (create these yourself as you go):

```
c-practice/
  basics/        # fundamentals exercises (I/O, loops, functions...)
  leetcode/       # one file per solved problem, e.g. 1-two-sum.c
  data-structures/ # your own linked list, stack, queue, BST, hash table
```

This folder is just a place to keep things organized — writing the code
is the part that teaches you anything, so none of it is pre-filled.
