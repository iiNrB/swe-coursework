grepsearch text inside files
locatefast indexed file search
manmanual for a command
gcccompile C code
gdbdebug a compiled program
makebuild multi-file projects
aptinstall/remove/update packages
dpkginstalled-package info

SYMBOLS

-xshort flag — e.g. ls -l
--wordlong flag — e.g. --help
>redirect output to file, overwrite
>>redirect output to file, append
<take input from file
|pipe — feed output into next command
&run command in background
&&run next command only if previous succeeded
;run commands one after another regardless
*wildcard — matches anything
~home folder
.current folder
..parent folder
/root folder / path separator
$variable value — echo $PATH
$1 $2script arguments
#comment line
$?exit code of previous command (0 = ok)

GCC FLAGS

-o nameset output executable name
-Wallshow all warnings
-ginclude debug info (for gdb)
সারাংশ: টার্মিনাল নেভিগেশন + ফাইল অপারেশন + gcc/gdb/make + redirection/pipe সাইনগুলো দৈনন্দিন লাগবে। GUI-তে না গিয়ে টার্মিনাল দিয়ে ল্যাবের C ফাইল কম্পাইল-রান প্র্যাকটিস করলে দ্রুত অভ্যস্ত হবে।
